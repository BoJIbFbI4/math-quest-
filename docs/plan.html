2. What the research says

Feedback must explain, with pictures

Feedback that only says right/wrong is the most common weakness of maths apps; it should be visual and show quantities so the child sees why. Progressive hints that let the child reach the answer keep them engaged. In a study of 193 children, the game features tied to gains were accuracy feedback, multiple attempts, hints and progressive levels. For young students, elaborated feedback beats accuracy-only feedback.

Concrete → pictorial → abstract

2nd-grade strategies are counting on, making ten (8 + 6 = 8 + 2 + 4), decomposing (13 − 4 = 13 − 3 − 1) and place value with base-ten blocks, where 10 ones become 1 ten. Ten frames show teen numbers as "one full ten plus some"; number lines show jumps. The game uses these exact models.

Gaming the system is real and costly

In tutoring software, systematic guessing and hint abuse are the classic patterns, and students who game a lot learned only about ⅔ as much. Less gaming fully mediated the learning gains of a maths game. Detection uses fast repeated wrong answers and hint-until-answer patterns, so the game blocks both by design (§3).

Praise the process

Process praise ("you kept trying") leads to more persistence after failure than person praise ("you're smart"), and person-focused responses are linked to maths anxiety. The praise lines are written about effort and strategy.

Retrieval + spacing for facts

Flashcard-style retrieval beat restudying for 2nd graders learning multiplication; missed facts should come back in later sessions; keep sessions short and frequent. The game uses 10-problem rounds and re-queues misses within the round and across rounds.

Touch targets and iPad storage

Young children miss small targets far more often than adults; NN/g suggests about 2 cm targets. Keys are at least 72 px. Safari deletes website storage after 7 days without a visit, but apps added to the Home Screen keep their own counter, so the iPad setup is "Add to Home Screen" plus a backup code in the parent zone.

Curriculum anchors

US: fluency within 20 and within 100 using place value (2.OA.B.2, 2.NBT.B.5). Russia: oral + / − within 100 with and without crossing a ten; the order of the times table varies by textbook. Italy: numbers to 100, skip counting, tables up to 10 in classes 2–3.

3. The learning loop for one problem

  1. Problem
    A big equation or a short story with the blank as a box. She types on the pad and presses ✓. 🔊 reads it aloud. 💡 opens help.
  2. Right, 1st try
    Celebration, star, sound, next problem after about 1.2 s. Counts as clean only if no help was used.
  3. Wrong #1
    Gentle wobble, "Not yet, look at the picture". The model opens. If the error matches a known bug, a one-line tip ("Did you add the extra ten?"). The pad locks for 1.5 s and the box clears.
  4. Wrong #2
    Strategy steps appear with the last step blank: 8 + 2 = 10, 10 + 3 = ?. Lock for 2.5 s.
  5. Wrong #3
    Worked solution is shown and animated. "Let's remember it." The same problem comes back 3 problems later and is saved to the review list for the next rounds.
Anti-guessing rules. No multiple choice. No length limit tied to the answer. No "too big / too small". Two wrong answers in under 2 s each extend the lock to 4 s with a "Slow down and think" turtle. Help never prints the answer, only countable pictures and steps ending in "?". Stars come only from clean first tries, so peeking at help costs stars but never blocks progress.

Scoring, unlocks, rewards

  • Round: 10 problems (parent can pick 5 / 10 / 15 / 20). Re-asks of failed problems are extra and don't change the score.
  • Stars from clean first tries: ≥ 90% → ★★★, ≥ 70% → ★★, ≥ 50% → ★. Best result per level is kept.
  • Unlock: level N+1 opens at ★★ on level N. Level 1 of every topic is always open.
  • Sticker book: every 5 stars earned (all rounds, repeats included, so practice pays) unlocks a new sticker; any sticker can be picked as her buddy on the home screen.
  • Review list: per topic-level, up to 30 missed problems; up to 3 are mixed into the next round; a clean answer removes it.

5. Screens and iPad details

  • Home: buddy with greeting, 6 topic cards with star counts, sticker book, language chips RU · EN · IT, parent gear.
  • Levels: 5 stops on a path, locked ones show a lock, stars under each.
  • Play: back, 10 progress dots, streak flame; problem card; answer box; 3 × 4 pad (1–9, ⌫, 0, ✓); 💡 and 🔊.
  • Round end: stars animate in, "clean x / 10", new sticker reveal, Again / Next level / Home.
  • Parent zone behind a gate (hold 2 s, then type the answer to a 2-digit × 1-digit problem): name, girl/boy wording, language, sound, read-aloud, round length, unlock all, per-level stats, "trouble spots" (most-missed problems), backup / restore code, reset with an in-page confirm.
  • iPad: no focusable inputs (no iOS keyboard, no zoom, no suggestions), touch-action: manipulation, no text selection or long-press callout, safe-area padding, 100dvh layout that works in portrait and landscape, keys ≥ 72 px, Home-Screen manifest + 180 px icon, sound unlocked on first tap, prefers-reduced-motion respected.
  • Mac: digits, Backspace and Enter on a hardware keyboard.

6. Architecture

No build step. Classic <script> tags share one global namespace MQ, so the game runs from file:// as well as from a web server. Content is data in JS, never fetched JSON.

Topic contract

MQ.topic({
  id: 'add', icon: '➕', hue: 210,
  gen(level, rng) {               // level 1..5, rng = seeded
    return {
      key: '8+5',                 // stable id for review list and no-repeat
      q: { kind: 'eq', parts: [8, '+', 5, '=', '?'] },   // or kind 'text' | 'story' | 'viz'
      answer: 13,
      viz: { type: 'tenframes', a: 8, b: 5, op: '+' },   // countable, no total
      steps: [[8, '+', 2, '=', 10], [10, '+', 3, '=', '?']]
    };
  },
  diagnose(p, given) { return given === p.answer - 10 ? 'tip.carry' : null; }
});

Problems are plain data, so they can be stored in the review list and re-rendered in any language. Steps are language-neutral token lists; word tokens like {w: 'tens', n: 6} are translated at render time.

7. Delivery

  • Mac: double-click index.html, or run ./serve.sh and open http://localhost:8080.
  • iPad, now: the Mac runs ./serve.sh; on the iPad open http://<mac-name>.local:8080 in Safari → Share → Add to Home Screen. Use the .local name, not an IP, because progress is stored per address. Needs the Mac awake on the same Wi-Fi.
  • iPad, always-on (later, needs your OK): put the same folder on a free HTTPS static host such as GitHub Pages; then a service worker can make it fully offline. Not done automatically because it publishes something.

8. Verification

  • Every topic × level × 300 seeds: integer answer, within the level's range, no negatives, regrouping exactly when the level says, equation tokens evaluate to the answer.
  • No repeats back-to-back within a round; review items mixed in.
  • Hint models never contain the answer as text.
  • Misconception detectors fire on the bug answers and not on the right answer.
  • i18n: same keys in RU / EN / IT; story templates render with no undefined for both genders; Russian plurals for 1, 2, 5, 11, 21, 22, 25.
  • Session engine: locks, attempts, star thresholds, unlock at ★★, lifetime stars.
  • Store: corrupt or missing data falls back to defaults; backup code round-trips.
  • Every js/ file is loaded by index.html; no external URL anywhere in the game.
  • Browser playthrough at desktop and iPad size: full round, wrong path to the 3rd miss, hint ladder, language switch, parent zone, reload keeps progress, console clean.
  • iPad simulator (real WebKit): round played, no zoom on double-tap, no keyboard pop-up, layout fits portrait and landscape.

10. Assumptions made while you were away

  • She's a girl, so Russian and Italian use feminine forms by default ("справилась", "Brava"); a parent switch changes it.
  • Times tables are in scope at 2nd grade (Italian and some Russian programmes include them); if her school hasn't started them, the topic stays at level 1 or can be ignored.
  • No timers or speed pressure; speed only matters for blocking guess-spam.
  • One child profile. A second profile is a small later change.
  • No hosting on the internet without your OK.
  • Russian multiplication is written 3 · 4 and division 8 : 2, as in Russian schools. If her school writes ×, change one line (ops) in js/i18n/ru.js.
  • Repeating an easy level still earns stars toward stickers. This rewards practice, but she can farm Level 1; say if stickers should need harder levels.
